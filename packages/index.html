每个包都对应站上某个项目的一部分，源码仓库与主项目是同一个。遇到问题直接在 GitHub 上开 issue 即可。

下载量取自 npm registry 的周统计，随时间变化；版本号同样是占位示例，换成你自己的 之后在 src/lib/packages.ts 里改就行。
