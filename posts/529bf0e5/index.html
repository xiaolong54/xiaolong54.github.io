前言

Hexo 是一个快速、简洁且高效的博客框架。本文将介绍如何使用 Hexo 搭建个人博客。

环境准备

安装 Node.js

前往 Node.js 官网 下载并安装 LTS 版本。

安装 Hexo CLI

常用命令

命令 说明
hexo new "title" 创建新文章
hexo server 本地预览
hexo generate 生成静态文件
hexo deploy 部署到远程仓库
hexo clean 清除缓存
