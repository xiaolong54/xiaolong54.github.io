## 欢迎

欢迎来到我的博客！这是我的第一篇博客文章。

## 关于本站

本站使用 [Hexo](https://hexo.io/) 框架搭建，部署在 [GitHub Pages](https://pages.github.com/) 上。

### 主要功能

- 📝 Markdown 写作
- 🏷️ 分类和标签管理
- 🔍 本地搜索
- 🌙 深色模式
- 📱 响应式设计

## 快速开始

### 创建新文章

```bash
hexo new "文章标题"
```

### 本地预览

```bash
hexo server
```

### 生成静态文件

```bash
hexo generate
```

### 部署到 GitHub

```bash
hexo deploy
```
